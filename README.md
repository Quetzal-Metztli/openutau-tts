# OpenUtau-TTS

Interfaz ligera en Python (PySide6) para usar el motor de síntesis de voz de [OpenUtau](https://github.com/openutau/OpenUtau) como un sistema de Texto a Voz (TTS) local.

## Sobre este proyecto
Este proyecto es **100% vibe coded** (sin orgullo). 

Me dedico principalmente a escribir y quería una herramienta para hacer los audios para mis videos usando OpenUtau. Me interesa la programación, pero no conozco lo suficiente como para escribir todo el código desde cero. No sé exactamente cómo funciona el código internamente, pero quería liberarlo para que cualquiera pueda usarlo. 

Si eres programador y ves cosas que se pueden mejorar, ¡los PRs son bienvenidos! (Y si no, también está bien, el proyecto está aquí para quien lo necesite).


## Requisitos
- dotnet-sdk
- pyside6

## Instalación
```

bash install.sh

```
